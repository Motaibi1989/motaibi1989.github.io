## ماذا تفعل هذه الصفحة؟

- إضافة اسم ورقم تجريبي.
- إنشاء رسالة واتساب تجريبية.
- إنشاء رابط موافقة.
- تغيير حالة الشخص: موافق، طلب تعديل، مخفي، حذف.
- عرض مثال Webhook JSON.
- حفظ البيانات محلياً في المتصفح فقط باستخدام LocalStorage.

## ملاحظات مهمة

- لا يوجد إرسال واتساب حقيقي في هذه النسخة.
- لا تستخدم أرقاماً حقيقية أثناء التجربة.
- الربط الحقيقي لاحقاً يحتاج Backend + Database + HTTPS + Webhook + WhatsApp Cloud API أو BSP Provider.
- لا تعرض رقم الجوال كاملاً للعامة إلا بعد موافقة واضحة من صاحب الرقم.
